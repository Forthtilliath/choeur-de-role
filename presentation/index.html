Chœur de Rôle

Site vitrine & espace membres d'une chorale — projet de démonstration

← → pour naviguer · S pour les notes · F plein écran

Le projet

Une chorale fictive à Angers mêlant chant choral et jeux de société. Toutes les données (choristes, concerts, actualités…) sont inventées — mais l'application est complète et fonctionnelle de bout en bout.

  • 🌐 un site public (vitrine)
  • 🔒 un espace privé réservé aux choristes
  • 🛠️ un back-office d'administration complet
Objectif portfolio : montrer une app réaliste, pas une simple landing page. L'univers « chorale + jeu de rôle » sert de fil rouge thématique.

Stack technique

Front

  • Next.js 16 (App Router) + React 19
  • TypeScript strict
  • Tailwind CSS v4
  • PWA (Serwist / service worker)

Back & infra

  • Supabase — Auth, Postgres, Storage, RLS
  • Cloudflare R2 — fichiers & images
  • Resend — email transactionnel
  • Sentry · Umami — monitoring & analytics

Architecture


Navigateur ──► Next.js (App Router, RSC + Server Actions)
                 │
                 ├─► Supabase   Auth (+ 2FA TOTP) · Postgres · RLS · Storage
                 ├─► Cloudflare R2   partitions, pistes audio, images
                 ├─► Resend   formulaire de contact
                 └─► YouTube Data API   playlist vidéos synchronisée
  • Rendu serveur par défaut, Row Level Security comme socle d'autorisation
  • Schéma & données de démo versionnés dans supabase/migrations/ (~75 migrations)

Site public — accueil

Page d'accueil entièrement éditable par blocs de contenu depuis l'admin (héro, histoire, raison d'être, direction artistique, pianiste).

Site public — contenus

  • Concerts à venir / passés, affiche et détail par représentation
  • Galerie photos (albums) et vidéos (playlist YouTube synchronisée)
  • Partenaires, événements externes
  • Formulaire de contact (Resend)
  • Mentions légales, CGU, politique de confidentialité

Galerie photos & vidéos

Albums photos avec lightbox · playlist vidéo tirée de l'API YouTube.

Espace choristes

Accès réservé aux membres connectés — authentification Supabase, double facteur (TOTP).

  • Actualités, calendrier des répétitions, liens utiles
  • Sondages internes
  • Comptes-rendus de bureau
  • Répertoire : partitions, paroles et pistes audio par pupitre

Trombinoscope

Filtrable par pupitre · export · respect de la visibilité choisie par chaque choriste (email / téléphone / adresse).

Carte des choristes

Choristes géolocalisés (Leaflet + clustering), adresses géocodées.

Espace bureau

Pour les membres élus du conseil d'administration.

  • Tâches de préparation des concerts, assignées aux membres
  • Projets, modèles de tâches réutilisables, catégories, durées
  • Glisser-déposer (dnd-kit), statuts (à faire / en cours / en attente / fait)
  • Comptes-rendus de réunion

Administration

Un back-office pour gérer l'intégralité du contenu :

MembresSaisons & pupitres ConcertsGalerie PartenairesCalendrier SondagesRépertoire ActualitésPage d'accueil Messages de contactJournal d'audit

  • Éditeur de texte riche (Tiptap), upload d'images & PDF
  • Export PDF (programmes de concert) et ZIP (répertoire)
  • Journal d'audit des actions sensibles

Qualité & robustesse

  • Tests unitaires — Vitest
  • Tests E2E — Playwright (Supabase local en CI)
  • CI GitHub : types · lint · tests à chaque push
  • Audit Lighthouse automatisé
  • CSP stricte + en-têtes de sécurité
  • Row Level Security sur toutes les tables
  • Validation d'environnement (Zod / t3-env)
  • PWA installable + mode hors-ligne

Tester en local


git clone https://github.com/forthtilliath/choeur-de-role.git
cd choeur-de-role
npm install
cp .env.local.example .env.local

npm run dev:e2e   # Supabase local (Docker) + serveur Next.js
                  # → http://localhost:3000

Données de démo incluses dans les migrations. Détails complets : SETUP.md.
